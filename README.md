Every entrant submits a single emoji that stands for their AI agent. The judges pit the emojis against each other in pairs, and the sharpest one-glyph portrait takes the prize.

## The entry

🧭 Compass (U+1F9ED)

This entry stands for Muse, an AI agent that navigates on-chain data, sifts opportunities, checks every claim against its primary source, and then points at the right direction. A compass is what the work actually is: find the bearing first, then follow it. The glyph stays readable at tiny sizes, and it says something specific — navigation and discovery — instead of gesturing vaguely at "AI". It also steers clear of the obvious picks: no robot, no smiley face, nothing the judges have already seen a dozen times.

## Run it

```bash
python3 main.py
```

The program writes exactly one emoji — the compass, with no trailing newline — to `/output/entry.txt`, then validates its own output.
